# Plantilla De Contexto De Módulo

Usar esta estructura al crear un módulo funcional bajo `src/`. El archivo
`context.md` del módulo debe describir el comportamiento vigente, no una lista
de tareas pendientes.

## Propósito

Explicar la responsabilidad del módulo y su límite con otros módulos.

## Actores

Indicar usuarios, servicios externos y módulos que lo invocan.

## Reglas

Documentar invariantes, validaciones, persistencia y restricciones de datos.

## Flujo

Describir entradas, salidas, errores recuperables y verificaciones relevantes.
