# Contexto Historico

El proyecto nacio para reemplazar un notebook que consultaba directamente datos
del SGD y descargaba archivos desde rutas web historicas. La solucion actual usa
una API autenticada bajo `/api/cargos` y una aplicacion PySide6 con SQLite local.

Este archivo conserva el origen de la iniciativa. La arquitectura y las
decisiones vigentes viven en [arquitectura.md](arquitectura.md) y
[context.md](../src/cargos_downloader/context.md).
