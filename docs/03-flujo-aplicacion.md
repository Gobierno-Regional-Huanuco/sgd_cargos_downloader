# Antecedente Del Flujo

La aplicacion evoluciono de una descarga directa a dos operaciones separadas:
sincronizar registros y descargar archivos desde el inventario local. Los
relacionados se guardan como vinculos y el Excel muestra solo principales.

El flujo vigente y sus limites estan en [arquitectura.md](arquitectura.md) y
[context.md](../src/cargos_downloader/context.md).
